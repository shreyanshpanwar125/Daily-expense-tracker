Daily Expense Tracker

A simple and user-friendly web application designed to help users manage their daily expenses, monitor spending habits, and maintain better control over their monthly budget.

📌 Project Overview

The Daily Expense Tracker allows users to record, update, delete, and organize their daily expenses. It also provides category-wise expense reports and a monthly budget feature to make expense management easier.

✨ Features

- Add Expenses: Record daily expenses with amount, category, date, and description.
- Edit Expenses: Update existing expense details.
- Delete Expenses: Remove unwanted expense records.
- Monthly Budget: Set and monitor your monthly spending budget.
- Category Filter: Filter expenses according to categories.
- Expense History: View all recorded expenses.
- Category Reports: Check category-wise spending summaries.
- Dashboard: View total expenses and spending information.
- Data Storage: Saves expense records in browser Local Storage.

🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Functionality and expense management.
- Local Storage – Storing expense data in the browser.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the "index.html" file.
4. Open it in your web browser (Google Chrome, Microsoft Edge, etc.).
5. Start managing your daily expenses.
